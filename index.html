11. Publicar no GitHub Pages

Passos para publicar este projeto a partir de um repositório.

Deploy estático
  1. Crie um repositório GitHub e envie o conteúdo desta pasta para a raiz.
  2. Abra Settings → Pages.
  3. Em Build and deployment, selecione Deploy from a branch.
  4. Escolha a branch main e a pasta /(root). Clique em Save.
  5. Aguarde a publicação. O endereço normalmente será https://USUARIO.github.io/REPOSITORIO/.
Dependências externas: este laboratório carrega bibliotecas por CDN. Para usar offline, você precisará baixar e versionar as dependências no repositório, respeitando as licenças.
